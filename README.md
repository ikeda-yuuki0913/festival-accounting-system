# festival-accounting-system

## 概要
文化祭での会計業務を効率化・正確化するために作成した、ブラウザ上で動作するPOSレジシステムです。
専用のサーバーやデータベースは用意せず、Google Apps Script (GAS) とスプレッドシートを連携させてデータ管理を行っています。

## 主な機能
* **バーコード（ID）による商品追加**
  * 入力フォームで商品のIDを読み取ると、購入リストに自動追加されます。バーコードを読み取る外部装置を使用することによるIDの入力、または手動での入力を想定しています。
* **リアルタイムな金額計算**
  * 数量の増減（＋・ーボタン）に合わせて、合計金額を計算して画面に表示します。
* **3種類の決済方法に対応**
  * 会計の確定時には「現金」「金券」「auPAY」の支払い方法に対応したボタンをクリックすることで、決済方法と販売時刻をスプレッドシートに自動記録します。
  * 記録後は画面を即座にリセットし、次のお客様の会計へ移行します。
* **売上集計機能**
  * 記録されたデータを「商品別の総売上」「決済方法別の合計金額」としてスプレッドシートの別シートへ自動で集計・整形して出力します。

## 使用技術
* **フロントエンド:** HTML, CSS, JavaScript
* **バックエンド / データベース:** Google Apps Script (GAS), Googleスプレッドシート
